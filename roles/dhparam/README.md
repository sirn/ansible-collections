# dhparam

Install the [Mozilla](https://ssl-config.mozilla.org/ffdhe2048.txt) ffdhe2048 Diffie-Hellman parameter file at `/usr/local/etc/ssl/ffdhe2048.txt`. The [haproxy](../haproxy/README.md) role references this path from its default configuration.

## Supported platforms

- FreeBSD

## Variables

This role has no variables.
